# OpenAI GPT-5.6 Sol — Basic

Minimal single-turn prompt using OpenAI GPT-5.6 Sol (the current GPT-5.6 flagship; `gpt-5` is deprecated).

## Requirements

- `OPENAI_API_KEY`
- OpenAI project access to `gpt-5.6-sol` (a `model_not_found` error means the project has not been granted that model)

## Run

```bash
cargo run
```
